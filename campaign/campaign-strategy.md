# UrbanSkin – Google Ads Campaign Strategy

## 1. Campaign Overview

UrbanSkin is a hypothetical men's grooming and skincare brand
preparing for its product launch.

The objective of the campaign was to generate early-access
sign-ups from potential customers in Delhi before the official
product launch.

### Campaign Details

| Setting | Configuration |
|---|---|
| Campaign Name | UrbanSkin Early Access Campaign |
| Campaign Type | Google Search |
| Network | Google Search Network |
| Location | Delhi, India |
| Languages | English & Hindi |
| Daily Budget | ₹50/day |
| Bidding Strategy | Maximize Clicks |
| Campaign Objective | Sign-ups / Lead Form Submissions |
| Campaign Status | Paused |
| Start Date | September 29, 2026 |
| Broad Match | Off |
| Dynamic Search Ads | Enabled |
| Ad Rotation | Optimize |

---

## 2. Business Objective

The campaign was designed to build an early-access customer
list before the UrbanSkin product launch.

The primary conversion was:

**Early-access / waitlist registration**

Users were directed to the UrbanSkin landing page, where they
could learn about the product range and submit their details.

| beard care products | Phrase | Commercial |
| men's skincare | Exact | Commercial |
| men's grooming kit | Exact | Transactional |

### Keyword Strategy

Broad match was intentionally kept off to maintain greater
control over search intent during the initial testing phase.

The campaign would prioritize keywords showing clear
commercial intent rather than broad informational searches.

Potential negative keywords would include:

- jobs
- careers
- tutorial
- DIY
- homemade

## 11. Hypothetical Optimization Scenario

If the campaign generated high CTR but a low conversion rate,
the first area to investigate would be the landing page.

Possible actions:

- Improve the headline-to-ad message match
- Make the value proposition clearer
- Reduce form friction
- Test different CTA copy
- Add social proof
- Test different landing-page layouts

If CTR was low, potential actions would include:

- Testing new headlines
- Improving keyword-to-ad relevance
- Refining keyword targeting
- Testing stronger CTAs

If CPC became too high, the campaign could be optimized by:

- Reviewing keyword relevance
- Adding negative keywords
- Improving ad relevance
- Reducing low-intent search terms

---

## 12. Key Learning

This project provided hands-on experience with the basic
workflow of a Google Search advertising campaign:

**Audience → Keywords → Ad Groups → Ad Copy → Landing Page
→ Conversion → Measurement → Optimization**

It also demonstrated how landing-page design and advertising
strategy need to work together to generate conversions.
